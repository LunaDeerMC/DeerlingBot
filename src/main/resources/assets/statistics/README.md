# 游玩统计图标

七张独立透明 PNG 均由图片生成工具制作，导出为 256×256 打包素材。
图案使用统一方块风格，与成就素材配套；这里不包含玩家数据或整张卡片。

| 文件 | 统计项目 |
|---|---|
| `playtime.png` | 累计在线时间 |
| `walking.png` | 走过的总路程 |
| `mining.png` | 累计挖掘 |
| `crafting.png` | 累计合成 |
| `fishing.png` | 钓鱼次数 |
| `trading.png` | 村民交易次数 |
| `elytra.png` | 鞘翅飞行距离 |

`StatisticsIconComponent` 首次使用时解码，按比例缩放并缓存为 128×128；
七行统计表和数据暂不可用的四行卡片共用这些图片，不再用几何图形手工绘制统计图标。
